# Como contribuir

1. Use Node 18 ou mais novo para os testes. O painel em si não precisa de nada além de um navegador.
2. Rode `npm test` antes de abrir o PR. Todos os testes precisam passar.
3. Regras de cálculo ficam em `src/` (sem DOM) com teste em `test/`; `src/app.js` só desenha.
4. Mensagens de commit em português, no imperativo curto.
